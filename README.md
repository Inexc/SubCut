**SubCut** — быстрый, легковесный и полностью автономный настольный ИИ-видеоредактор для Windows.

Создан специально для клипперов, рилсмейкеров и авторов контента, которые устали тратить часы на ручное вырезание пауз, подгонку субтитров и размытие фонов для коротких видео (Reels, Shorts, TikTok).

> [!NOTE]
> Приложение работает **полностью локально** на вашем компьютере: использует аппаратное ускорение видеокарты (NVIDIA NVENC) и локальную нейросеть Whisper. Видеофайлы **никогда не загружаются в облако**, нет очередей на рендер и нет ежемесячных подписок.

## 🚀 Основные возможности

### ✂ 1. Умное удаление пауз по голосу (AI Voice VAD)
- **Анализ речи, а не децибел шума:** в отличие от классических фильтров громкости, SubCut анализирует фактическую речь человека через локальный движок `faster-whisper`.
- **Работает при громкой музыке:** точно определяет паузы молчания даже при громком саундтреке в аниме, клипах или играх.
- **Бесшовные склейки:** адаптивный запас дыхания (120 мс) и 40-мс аудио-микрофейды без щелчков и резких обрывов слов.
- **Два режима на выбор:** «Умный ИИ (по речи)» для видео с музыкой и «По громкости (FFmpeg dB)» для студийных подкастов.

### 💬 2. Динамичные караоке-субтитры без простыней текста
- **Нарезка по смысловым предложениям:** речь автоматически делится на короткие реплики по 3–5 слов или по одному предложению под звук речи. Никаких гигантских абзацев на пол-экрана.
- **3 визуальных стиля:**
  - **Hormozi / Viral:** крупный акцентный капс с пословной караоке-подсветкой активного слова.
  - **Плашка (Box):** минималистичная полупрозрачная контрастная подложка.
  - **Классик:** чёткий белый текст с глубокой черной обводкой.
- **Полная настройка:** размер шрифта от 32 до 90 px, вертикальная позиция (снизу, по центру, сверху) и мгновенный предпросмотр.

### 📱 3. Вертикальный формат 9:16 с размытием фона
- Автоматическая адаптация горизонтальных видео (16:9 из YouTube, фильмов или аниме) под вертикальный формат Reels/Shorts без чёрных полос.
- Видео центрируется, а верх и низ динамично заполняются плавно размытой копией того же кадра (`boxblur`) со строгим сохранением пропорций пикселей (SAR 1:1, DAR 9:16).

### 🎨 4. Цветовые фильтры в один клик
- **Anime Punch:** сочные цвета (+25% насыщенности), контраст и контурная резкость (`unsharp`) — картинка становится объёмной на экранах смартфонов.
- **Кино / Тёмный:** глубокий кинематографичный контраст и приглушенные холодные тени.
- **Crisp:** микроконтраст и чёткость деталей без изменения цветовой гаммы.

### 🎵 5. Фоновая музыка с умным Auto-Ducking
- Добавление любого MP3/WAV фонового трека.
- **Сайдчейн-компрессия:** когда спикер начинает говорить, фоновая музыка автоматически и плавно приглушается на выбранную глубину (-12 dB, -16 dB, -20 dB). Во время пауз музыка плавно возвращается на исходную громкость.

### 🖼 6. Встроенная студия генерации обложек
- Интерактивный генератор постеров 9:16 прямо в приложении.
- Выбор выразительного момента на таймлайне + лента ключевых кадров.
- Наложение кликабельного заголовка в стилях Hormozi, Neon или Minimal с экспортом в высоком разрешении (JPG/PNG).

### ⚡ 7. Аппаратный экспорт и пресеты платформ
- Аппаратное кодирование через чип **NVIDIA NVENC** (с авто-переключением на процессор при необходимости).
- Готовые пресеты:
  - **Instagram Reels & YouTube Shorts** (1080x1920, высокий битрейт, 60/30 fps).
  - **Telegram Compact (< 50 МБ)** — автоматический расчёт битрейта, чтобы ролик весил строго меньше 48 МБ и отправлялся файлом без сжатия.
  - **Чистый звук (MP3 320 kbps)** — выгрузка только аудиодорожки без пауз.
  - **Монтажный проект (.EDL CMX 3600)** — экспорт таймкодов нарезки для DaVinci Resolve и Adobe Premiere Pro.
  - **Файл субтитров (.SRT)**.

## 🛠 Стек технологий

- **Desktop Framework:** [Tauri v2](https://v2.tauri.app/) (легковесный нативный контейнер, бинарник ~4.9 МБ)
- **Backend:** Rust (многопоточная обработка задач, неблокирующий IPC)
- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Media Engine:** Local [FFmpeg](https://ffmpeg.org/) (аппаратный NVENC, sidechain компрессия, фильтры размытия и ASS субтитры)
- **Speech AI:** Local [Faster-Whisper](https://github.com/SYSTRAN/faster-whisper) (INT8 квантование, пословные таймкоды, русский контекст)
